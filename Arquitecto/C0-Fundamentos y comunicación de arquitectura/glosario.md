# Glosario de términos

Referencias breves agrupadas para los conceptos clave mencionados en el módulo.

## Decisiones y riesgo
- <a id="trade-off"></a>**Trade-off**: decisión donde se renuncia a algo para ganar otra cosa; hace explícito qué se sacrifica y qué se obtiene.
- <a id="coste-de-cambio"></a>**Coste de cambio**: esfuerzo, tiempo y dinero necesarios para modificar una decisión ya tomada.
- <a id="lock-in"></a>**Lock-in**: dependencia fuerte de un proveedor o tecnología que encarece o bloquea el cambio.

## Fiabilidad y cumplimiento
- <a id="idempotencia"></a>**Idempotencia**: repetir una operación no altera el resultado final; protege frente a reintentos o duplicados.
- <a id="compliance"></a>**Compliance**: grado en que el sistema cumple normas legales, sectoriales o internas aplicables.

## Equipo y presupuesto
- <a id="skillset"></a>**Skillset**: capacidades reales del equipo para diseñar, construir y operar la solución.
- <a id="budget"></a>**Budget**: recursos económicos disponibles que limitan alcance, calidad y velocidad.
